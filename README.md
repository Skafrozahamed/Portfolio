# Sk Afroz Ahamed - Portfolio Website

A modern, fully responsive personal portfolio website showcasing my professional experience as a Maintenance Engineer and my passion for Electronics, IoT, and Embedded Systems.

## 🚀 Features

- **Modern UI/UX**: Clean, professional design with Apple/Tesla-inspired aesthetics
- **Fully Responsive**: Optimized for mobile, tablet, and desktop devices
- **Dark/Light Mode**: Toggle between themes with persistent preference storage
- **Smooth Animations**: Fade-in effects, parallax scrolling, and interactive transitions
- **Interactive Elements**: Hover effects, smooth scrolling, and dynamic content
- **SEO Optimized**: Proper meta tags and semantic HTML structure
- **Fast Loading**: Optimized CSS and JavaScript for performance

## 📋 Sections

1. **Hero Section**: Eye-catching introduction with professional badges and call-to-action buttons
2. **About Me**: Comprehensive professional summary highlighting expertise and experience
3. **Professional Experience**: Timeline view of work history at Gautam Solar and Indian Railways
4. **Skills & Expertise**: Categorized skill sets including:
   - Maintenance Engineering
   - Electrical Systems
   - Industrial Machines
   - Programming (C, C++, Python)
   - IoT & Embedded Systems
   - Tools & Software
5. **Projects**: Featured projects with detailed descriptions:
   - Automatic Railway Signal & Gate System (ESP32)
   - Real-Time Ambient Gas Monitoring System (IoT)
6. **Education & Certifications**:
   - B.Tech ECE from Cooch Behar Government Engineering College
   - Higher Secondary Education
   - Indian Railways Industrial Training Certificate
7. **Contact**: Multiple ways to connect with form validation

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with CSS Variables for theming
- **Fonts**: Inter & Poppins from Google Fonts
- **Icons**: Font Awesome 6.4.0
- **Features**:
  - CSS Grid & Flexbox for layout
  - CSS Custom Properties (variables)
  - Intersection Observer API for animations
  - Local Storage for theme persistence
  - Form validation

## 🎨 Design Principles

- **Minimalist**: Clean layout with plenty of white space

## 🚀 Getting Started

### Local Development

1. Clone the repository or download the files
2. Open `index.html` in your web browser
3. No build process required - it's vanilla HTML/CSS/JS!

### Deployment

This portfolio can be deployed to any static hosting service:

- **GitHub Pages**: Push to repository and enable GitHub Pages
- **Netlify**: Drag and drop the folder or connect your repository
- **Vercel**: Import project and deploy
- **Cloudflare Pages**: Connect repository and deploy

## 📝 Customization

### Changing Colors

Edit the CSS variables in `css/styles.css`:

```css
:root {
    --primary-color: #3b82f6;
    --secondary-color: #8b5cf6;
    --accent-color: #f59e0b;
    /* Add more custom colors */
}
```

### Adding Projects

Add new project cards in `index.html` within the `#projects` section following the existing structure.

### Updating Content

Simply edit the text content in `index.html` - all sections are clearly labeled with comments.
